# LetzShopy Vendor — Capacitor Android Environment

This project uses **Capacitor 8 stable** for the Android wrapper.

## Application identity

- App name: `LetzShopy Vendor`
- Android application ID: `in.letzshopy.vendor`
- Hosted dashboard: `https://dashboard.letzshopy.in`

The existing Next.js dashboard is server-rendered and depends on Vercel API/server routes. For that reason the first Android shell loads the hosted dashboard rather than attempting a static Next.js export.

## Required local environment

1. Node.js 22 LTS or newer.
2. Android Studio Otter 2025.2.1 or newer.
3. Android SDK 36 installed through Android Studio.
4. Git.
5. A physical Android device with USB debugging enabled, or an Android emulator.

Capacitor 8 requires Node.js 22+. The Android project generated by Capacitor 8 targets the current Android toolchain.

## One-time setup on Windows

From the repository folder:

```powershell
git fetch origin
git switch audit/capacitor-android-final
git pull --ff-only

powershell -ExecutionPolicy Bypass -File .\scripts\setup-capacitor-android.ps1
```

The script will:

1. verify Node 22+;
2. run `npm.cmd install` and synchronize `package-lock.json`;
3. run Capacitor Doctor;
4. create the native `android/` project if it does not exist;
5. run `npx.cmd cap sync android`;
6. show the generated Git changes.

To open Android Studio automatically:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup-capacitor-android.ps1 -OpenAndroidStudio
```

## Useful commands

```powershell
npm.cmd run cap:doctor
npm.cmd run android:sync
npm.cmd run android:open
npm.cmd run android:run
```

## Preview or development server

The default native shell points to:

```text
https://dashboard.letzshopy.in
```

For temporary testing against another HTTPS deployment, set `CAPACITOR_SERVER_URL` before syncing:

```powershell
$env:CAPACITOR_SERVER_URL="https://your-preview.vercel.app"
npm.cmd run android:sync
npm.cmd run android:open
```

Clear the variable before preparing a production build:

```powershell
Remove-Item Env:CAPACITOR_SERVER_URL -ErrorAction SilentlyContinue
npm.cmd run android:sync
```

## Files that should be committed after first setup

- `package-lock.json`
- `android/`
- any intentional Capacitor configuration changes

Do **not** commit:

- Android signing passwords
- release keystores
- `local.properties`
- personal SDK paths
- Firebase service credentials until the project has an approved secure handling process
